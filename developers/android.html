The Android apps ​

The display app (instead of Fully Kiosk) ​

android/ is a tiny app (party.froghub, minSdk 22, so it runs on Fire OS 5): a full-screen WebView that

  • keeps the screen on and plays sound without a tap;
  • gives the microphone to Frog Hub's own site only, and stays on that site;
  • retries every 10 seconds when the server can't be reached;
  • never closes on Back.

Five quick taps in the top-left corner open its settings (address, open on startup, exit). It asks for Frog Hub's address on first start, or set it over adb:

sh
adb shell am start -n party.froghub/.MainActivity -e url https://froghub.example

Debug it with chrome://inspect over adb.

Old Fire tablets and Let's Encrypt ​

Fire OS 5 doesn't trust Let's Encrypt's root certificates (ISRG Root X1 and X2), so its WebView refuses sites that use them and shows a black page. The app bundles both roots (res/raw/) and, when the only error is "untrusted", checks the site again itself (IsrgTrust.java: the full chain against those roots, the hostname, and the same certificate) before going ahead.

Its WebView is Chrome 59, which has no ES modules, so vite.config.js also builds a legacy version for Chrome 59.

Building it ​

Build with android/build.sh on an x86 computer with the Android SDK (its build tools don't run on ARM). It signs with that computer's debug key, so updates built there install over the old one.

The admin app ​

android-admin/ wraps the admin page as a phone app (party.froghub.admin, minSdk 22 = Android 5.1), with the same Let's Encrypt check. It asks for the site on first start. Build it like the display app, with android-admin/build.sh.
