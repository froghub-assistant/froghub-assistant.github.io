Environment variables ​

Setup writes the ones you need. For the API brain they go in ~/.config/froghub/standalone.env; keep secrets there rather than in the service unit.

Both brains ​

VariableMeaningDefault
FROGHUB_PORTThe server's port on 127.0.0.18790
FROGHUB_BIG_MODELThe bigger model think_harder hands hard questions to; none turns it offSonnet
FROGHUB_RECIPEAPI_KEYA recipeapi.io key, overriding ~/.config/froghub/recipeapi.key
FROGHUB_MEALDB_KEYYour own TheMealDB key1 (the free one)
FROGHUB_FREESOUND_KEYA Freesound API key, overriding ~/.config/froghub/freesound.key

The Claude Code brain ​

VariableMeaningDefault
FROGHUB_TIMEOUTSeconds to wait for a reply45
FROGHUB_CLEAR_AFTERMinutes of quiet before its conversation is cleared; 0 never30

The API brain ​

VariableMeaningDefault
ANTHROPIC_API_KEYAn Anthropic API key. Without one, it uses the OpenAI-compatible API
FROGHUB_MODELThe Claude modelclaude-haiku-5-5
FROGHUB_FALLBACK_URLAn OpenAI-compatible API's base URL, used without an Anthropic key or when it fails: LM Studio (http://<pc>:1234/v1), Ollama (http://<pc>:11434/v1) or OpenAI (https://api.openai.com/v1)
FROGHUB_FALLBACK_MODELThe model name there, e.g. qwen3:8b on Ollama
FROGHUB_FALLBACK_KEYIts API key, if it wants one (OpenAI does; LM Studio and Ollama don't)
FROGHUB_FALLBACK_TOOLSbasic offers that model only reply, memory and web search, for a small model that gets lost among many toolsall of them
FROGHUB_SEARCH_URLA SearXNG instance for that model's web search, with format=json allowedDuckDuckGo
FROGHUB_PROMPTThe assistant's rules~/.config/froghub/assistant.md
FROGHUB_MEMORYIts memory file~/.config/froghub/memory.md

Installing ​

VariableMeaningDefault
FROGHUB_DIRWhere install.sh puts Frog Hub (and upgrade.sh and remove.sh look for it)~/froghub
FROGHUB_REPOThe git repo install.sh fetcheshttps://github.com/froghub-assistant/froghub.git
VOICE_BINDThe address the voice containers listen on, the one Home Assistant reaches them on127.0.0.1
