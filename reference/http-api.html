HTTP API ​

Both brains serve the same API on 127.0.0.1:8790 (FROGHUB_PORT). Caddy passes /api/* on to it from your site; /local/* is only reachable from the server itself.

Admin only routes need an X-Admin-Token header: POST /api/admin/unlock {"pin": "1234"} returns one, and it expires after a while. Too many wrong PINs lock it for a few minutes.

Asking ​

RouteWhat it does
POST /api/askA question from a display: {text, personality, speaker, device, conversation_id, devices}. Returns {text, continue_conversation, actions, display?}
POST /api/admin/rememberThe admin page asking the assistant to remember, change or forget something: {text}. Admin only

Announcements and displays ​

RouteWhat it does
POST /local/announceSay something on the displays: {say, show?}, {prompt}, {audio, title?}, {stop_audio: true} or {goodnight: true, sound?, minutes?}, with optional to, area, at_night, personality. See Announcements
POST /api/announceA display's 📢 message: {text, to?, device, name}
POST /api/admin/announceAn announcement from the admin page. Admin only
GET /api/announcements?after=&device=&name=&area=Each display's poll (every 5 s): new announcements, plus anything queued for it as command
GET /api/displaysThe displays that are on
GET /api/admin/displaysEvery display that has ever checked in. Admin only
POST /api/admin/displays{id, action: wipe | welcome | forget | cancel | set, set?}. Admin only

Alarms ​

RouteWhat it does
GET /api/alarmsThe alarms and timers
POST /api/alarms/doneStop a ringing one: {id}
POST /api/alarms/snoozeSnooze a ringing one for 9 minutes: {id}
POST /api/alarms/manage{tool: set_alarm | set_timer | cancel_alarm, args}, with the same rules as the assistant's tools. Admin only

Settings and policy ​

RouteWhat it does
GET /api/instanceThe house: {site, haUrl, timeZone, kids}
GET /api/policy / POSTWhat the assistant may use. Posting is admin only
GET /api/settings / POSTSettings shared by every display (the Home Assistant token only with X-Admin-Token). Posting is admin only
GET /api/audience?device= / POST {device, grownUps}Whether a display is a grown-ups' one. Posting is admin only

Radio and lists ​

RouteWhat it does
GET /api/radio/<id>The stream of an http-only station play_radio chose, relayed for the https page. Ids last a day
GET /api/admin/listsHome Assistant's to-do lists: {lists: [{id, name, items, allowed}]}. Admin only
POST /api/admin/lists {allowed: [ids]}Which lists the assistant may use. Admin only

Pairing ​

RouteWhat it does
POST /api/pairA new pairing code for a display's QR code: {code}
GET /api/pair?code={waiting: true} until a grown-up approves it, then the shared settings and token, once
POST /api/admin/pair {code}Approve it. Admin only

Admin ​

RouteWhat it does
POST /api/admin/unlock {pin}An admin token
GET /api/admin/check{admin}: whether the token is still good
POST /api/admin/lockEnd admin mode
GET /api/admin/memoryThe assistant's memory files: [{file, text, modified}]. Admin only
GET /api/admin/history?before=&limit=The History, newest first: {items, more}. Admin only
POST /api/admin/history {clear: true}Clear it. Admin only
POST /api/wakeword/sample?kind=wake|other&speaker=A wake word recording (raw 16-bit 16 kHz mono PCM). Admin only
GET /api/wakeword/countsHow many recordings there are. Admin only
GET /api/pingWhether the server is up
